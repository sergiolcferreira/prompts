# Sérgio Ferreira — Biblioteca de Prompts de IA

Este repositório reúne prompts autorais testados em uso real, organizados por categoria e publicados em uma vitrine web.

## Estrutura proposta

- `prompts/` — arquivos Markdown independentes, versionáveis e reutilizáveis
- `exemplos-imagem/` — exemplos visuais de resultados
- `index.html` — vitrine pública atual
- arquivos HTML auxiliares — experiências específicas

## Categorias iniciais

- `prompts/carreira/`
- `prompts/produtividade/`
- `prompts/idiomas/`
- `prompts/imagem/`
- `prompts/analytics/`

## Padrão de cada prompt

Cada arquivo deve conter, sempre que aplicável:

- título
- categoria
- melhor IA / compatibilidade
- versão
- data de atualização
- autor
- objetivo
- instruções de uso
- prompt completo
- observações e limitações

## Publicação

A `main` continua sendo a versão publicada. Mudanças estruturais devem ser preparadas em branch e revisadas via Pull Request antes do merge.
